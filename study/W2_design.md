# W2 강화 웜업 만들기 (E3, W2 학습 전 고정)

- 작성: 2026-11-10. 근거: 명세 v0.13 3.7절, 이탈 기록 D-MAIN-1(연구자 결정: 목표 수집 성공률 70% 이상, 시연 수 사다리).
- 코드: `study/collect_demos.sh`, `study/a1_prepare.py --subset`, `study/train_a1.py`, `study/build_w2.py`. W2 학습 전에 커밋한다.

## 1. 시연

- 모션 플래너로 **A1과 별도의** 시연 2,048개를 만든다: `collect_simpler -e PutOnPlateInScene25Main-v3 --num_traj 2048 --seed=200 --num_procs 4` (A1은 시드 100). 생성 집합 해시를 기록한다.
- 전처리: A1과 같다 (작은 행동 제거, 성공 6스텝 뒤 절단, `bridge_orig` 정규화, 렌더 원본 이미지).
- 사다리: 파일 이름 정렬 → 시드 0 순열 → 앞 N개 (N = 256, 512, 1,024, 2,048). 작은 집합이 큰 집합에 포함된다.

## 2. 학습과 병합

- 출발: W1 + 온라인 갈래와 같은 새 LoRA (C2), 초기화 시드 0.
- 원 웜업 레시피(RL4VLA README): 2,000스텝, 학습률 5e-4, 전역 배치 32, AdamW 기본값, 상수 학습률. 손실·표본 순서는 A1과 같다 (`train_a1.py`).
- **원 레시피와 다른 점:** 원 웜업은 이미지 증강(`--image_aug True`)을 썼다. 여기서는 증강하지 않는다 (A1과 같은 학습기). W2의 강도는 아래 성공률 기준으로 정하므로 증강 유무는 W2 선택 규칙에 이미 반영된다.
- 수치 경로: 결정적 math (재현용).
- 병합: LoRA를 W1 가중치에 합쳐(`merge_and_unload`) W1과 같은 형식의 체크포인트로 저장한다. **value head는 저장하지 않는다** (W1과 같이, 각 갈래가 학습 시드로 새로 만든다). 설정 파일(정규화 통계 등)은 W1 것을 그대로 복사한다.
- 병합 검사: 병합 모델과 (W1 + LoRA) 모델의 행동 분포를 진단 상태 64개에서 비교한다. 위치 합 KL 평균 < 0.01이면 통과 (bf16 반올림 차이만 허용).

## 3. 선택

- 학습 조건 수집 성공률: 학습 환경(Main-v3, train), 온도 1.0, K0, **512 에피소드** (태그 `w2-check`, 64 × 8, 시드 1,000 + 배치), 성공 = Y. 같은 집합으로 W1도 잰다 (참고값).
- **N = 256부터 차례로 학습·측정해 성공률이 70% 이상인 첫 N을 W2로 고른다.** 넷 다 70% 미만이면 N = 2,048을 W2로 쓰고 그 사실과 성공률을 보고한다 (사다리를 넓히지 않는다).
- 공개: 후보별 성공률과 선택 결과 (`public/w2_selection.json`). 웜업 후보의 성공률은 E1·E3 결과와 무관하므로 맹검 대상이 아니다.

## 4. E3

- 갈래 A2⁺·A3⁰, 학습 시드 각 5개 (1~5, 과제 표본 태그 `e3-seed{s}`), 390라운드, 결정적 경로, W1에서 고른 설정 그대로 (명세 3.5절). 평가 = E1 평가 묶음, E4-b 포함, 출발 모델 W2.
