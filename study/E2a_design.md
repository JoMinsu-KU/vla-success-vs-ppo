# E2-a 누적 기울기 진단 구현 규칙 (3단계, 실행 전 고정)

- 작성: 2026-11-10. 근거: 명세 v0.13 3.6절 E2-a, G-PRE 고정 문서 3절(C10 민감도)·6절(Δθ = 계보 optimizer 상태에서 한 스텝, 기울기 2종 따로).
- 코드: `study/e2a.py`. 이 문서와 코드는 E2-a를 처음 실행하기 전에 커밋한다. 바꾸면 `pilot/deviations.md`에 기록한다.
- 결과(성공 여부와 함께 움직이는 값)는 `<W>/blinded/e2a/`에만 쓴다. 공개는 진행 상태와 검사 통과 여부만.

## 1. 단위와 입력

- 단위: (계보 s, 분기 지점 p). 계보 = E1 A3⁰ 시드 1~8, p ∈ {20, 150, 300} → 24개.
- 정책: 계보의 `r(p−1)` 체크포인트(LoRA + value head + 두 Adam 상태). 결정적 math 경로. E2-b의 출발점과 같다.
- 배치 (모두 이 정책, 학습 환경 Main-v3 train, 온도 1.0, K0, 64 × 80):
  - 배치 1 = **공통 배치** = 계보의 p번째 라운드 배치 (태그 `e1-seed{s}-round{p−1}`, 샘플링 시드 100,000·s + p − 1). E2-b 첫 업데이트와 같은 배치다.
  - 배치 2~8: 태그 `e2a-seed{s}-p{p}-b{b}`, 시드 900,000,000 + 1,000,000·s + 1,000·p + b.
  - 진단 배치(학습 조건): 태그 `e2a-diag-seed{s}-p{p}`, 시드 같은 식에 b = 99.
  - 실행 OOD 진단 배치: Position·EEPose·PositionChangeTo 각 1배치 (test 물체 집합), 태그 `e2a-ood-{조건}-seed{s}-p{p}`, b = 101·102·103.
- θ_old의 log-prob·value는 학습기와 같은 teacher forcing(train 모드)으로 다시 계산한다 (C10 정렬, ratio = 1).

## 2. 기울기 (진단 크기 m ∈ {1, 2, 4, 8} = 배치 1..m)

정의는 명세 그대로다: 규칙 r의 advantage를 **배치 1..m을 합친 버퍼에서 한 번** 계산·정규화하고(`ppo.advantages_and_returns`를 합친 RoundBatch에 적용), 손실은 학습기의 손실(정책 7 · PPO 클리핑 손실의 전이 평균 + value 1 · 원 value 손실의 전이 평균)을 θ_old에서 미분한다.

**계산 방법 (정의와 수학적으로 같음):** θ_old에서는 ratio가 정확히 1이라 클리핑이 작동하지 않고, 정책 손실 기울기는 −(7/n)·Σᵢ Aᵢ∇log πᵢ로 advantage에 선형이다. 그래서
- 배치마다 기울기 합 S₁ = Σ∇log π, S_A = Σ A^raw∇log π (A^raw = 정규화 전 GAE), S_Y = Σ Y∇log π, S_V = Σ∇ℓ_V를 한 번씩 계산해 크기별로 누적한다.
- O±·O⁺·C±는 advantage가 각각 u = Y·Y·A^raw의 1차식(α·u + β)이므로 기울기 = −(7/n)(α S_u + β S₁). α, β는 공식 함수가 낸 advantage에 맞춰 구하고, 잔차 최대값이 10⁻⁴를 넘으면 오류로 멈춘다.
- C⁺(정규화 뒤 음수 마스킹)는 1차식이 아니므로 크기마다 공식 advantage로 직접 계산한다.
- value 기울기는 규칙과 무관하다: (1/n)·Σ_b S_V.
- **검사 (매 단위):** 크기 1의 C± 정책 기울기를 직접 계산한 값과 분해로 얻은 값의 코사인 ≥ 1 − 10⁻⁵, 노름 상대오차 ≤ 10⁻³. 통과하지 않으면 그 단위를 실패로 기록하고 멈춘다.

**세 층위 (행 O, C마다 ± 대 ⁺):**
1. 정책 손실 기울기 (LoRA 파라미터)
2. 총 기울기 = 정책 + value (LoRA + value head)
3. Δθ: 계보의 Adam 상태에서 총 기울기로 **한 스텝** (기울기 노름 클리핑 10 → value optimizer → policy optimizer, 학습기와 같은 순서). 스텝마다 체크포인트 상태로 되돌린다.

각 층위에서 cos(g±, g⁺), ‖g⁺‖/‖g±‖, 두 노름. 노름이 10⁻¹²보다 작으면 코사인은 "정의 불가"로 둔다 (0이나 1을 넣지 않음).

**기울기 크기 보정 진단 C⁺ₙ:** C⁺ 정책 기울기를 C± 정책 기울기의 노름으로 다시 키운 뒤 같은 value 기울기를 더해 한 스텝 → Δθ를 C±와 비교 (보정 진단으로만 부른다).

## 3. C10 보정 민감도 (크기 1, G-PRE 3절)

전이마다 w̄ = clip(exp(log p₀ − log q₀), 0.5, 2) (p₀ = teacher forcing, q₀ = 생성 때 저장값, joint 7토큰, stopgrad; G2 S7과 같은 정의)를 정책 손실 항에 곱한 정책 기울기를 네 규칙에 대해 계산하고, 보정 전 기울기와의 코사인·노름 비를 보고한다.

## 4. 정책 변화 진단 (크기 1과 8, 규칙 4개 + C⁺ₙ)

한 스텝 뒤 정책 π_new와 π_old를 비교한다:
- 학습 조건 진단 상태 64개 (진단 배치에서 균등 추출, 시드 10,000 + p): KL(π_old ‖ π_new), 위치 7개 정확한 KL 합의 상태 평균 (KL 탐침과 같은 정의).
- 실행 OOD 진단 상태: 조건마다 64개 (같은 방식), 조건별 값과 평균.
- 행동 엔트로피: 위 상태들에서 위치 평균 엔트로피의 전후.
- 다른 배치(진단 배치)의 성공 궤적 행동과 실패 궤적 행동 각각 최대 256개 전이 (균등 추출): 평균 joint log π 변화.
- 회복 행동 log-likelihood 변화 (명세 3.6절 (i)): 크기 1의 π_new LoRA 파라미터(규칙별)를 `<W>/runs/e2a/<단위>/`에 저장해 두고, E4-b 기준 상태와 회복 행동이 준비되면 그때 계산한다.

## 5. 비용

배치 수집 12회 + 기울기 계산 (배치당 순전파 1회 + 역전파 4회, 공통 배치는 +3회) + C⁺ 크기별 15배치분 + 순전파 진단. 단위당 약 5~6 GPU시간, 24단위 약 130~150 GPU시간 (G-PRE 추정 약 200 안).
