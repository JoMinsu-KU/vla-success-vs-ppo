# E4-a 배포형 교란 평가 — 제안 (연구자 승인 전)

- 작성: 2026-11-10. 상태: **제안.** 명세 v0.13 3.8절은 E4-a의 뼈대만 정했고, 9.2절 체크리스트의 "E4-a 교란 정의(종류, 크기, 단계 기준 시점)와 도달률 보고 규칙"은 G-PRE에서 고정하지 않았다. 승인되면 이 문서를 고정하고 이탈 기록(D-MAIN-3)에 남긴 뒤 러너 계획에 넣는다.
- 코드: `study/e4a.py` (아래 제안값으로 작성, 승인 전에는 실행 계획에 없음).

## 제안

| 항목 | 제안 | 근거 |
|---|---|---|
| 백엔드·경로 | GPU 64개 배치, E1 평가 경로(flash_attention_2, K0, 온도 0.6, 배치마다 재구성) | 배포형 = E1과 같은 조건의 실제 실행 중 교란 |
| 조건·에피소드 | 학습 조건(ID, `PutOnPlateInScene25Carrot-v1` train), 고정 집합 192개 (태그 `main-e4a-…`, E1 집합과 별도), 교란마다 같은 집합 | 교란은 학습 조건 과제 단계에 정의됨. 192는 E1 조건당 수와 같음 |
| 교란 | 대조·R-a′·R-b·R-c (E4-b와 같은 연산·크기) | E4-b와 같은 교란이어야 둘을 나란히 읽을 수 있다. 원래 R-a(물체 순간 이동)는 관통 문제로 G-PRE에서 R-a′로 바꿨다 |
| 시점 | R-a′·R-c: 그 환경의 집기 래치가 처음 켜진 스텝 직후. R-b: 그 2스텝 뒤 (S_rec 기준 상태와 같은 "집기 2스텝 뒤") | 명세 표의 "처음 집기가 감지된 직후", "집은 뒤 고정 스텝 수" |
| 남은 시간 | 원래 80스텝의 나머지 (추가 없음) | 명세 3.8절 E4-a |
| 보고 | 도달률(교란이 걸린 에피소드 비율), 도달 조건부 성공률("조건부"로 표기), 무조건부 성공률(전 에피소드), 대조 대비 차이 | 명세 3.8절 |
| 대상 체크포인트 | E1(모든 갈래·시드)과 E3의 최종 체크포인트 | 명세 3.1절 E4 행 "모든 최종 체크포인트". E2-b는 E4-b만 (명세 3.6절) |
| 비용 | 체크포인트당 4교란 × 3배치 = 12배치 (약 40분), E1·E3 약 40개 → 약 27 GPU시간 | |
| 맹검 | 에피소드 결과는 `blinded/`에만 | |
