## S9 실행 조건 (같이 고정)

- 학습 시드 0 (LoRA A 초기화 시드 = 0), 갈래당 최대 50라운드, 환경 64 × 80스텝, 온도 1.0, K0, 학습 과제 분포(Main-v3 train).
- 라운드별 episode_id: SHA-256(`g2s9-<갈래>-seed0-round<r>-ep<k>`), 배치마다 장면 재구성.
- 수치 설정: C11 결정적 설정(엄격 모드). attention 경로는 S6 결과로 정한 하나를 두 갈래에 같게 쓴다 (`--path`).
  **선택 규칙:** S6에서 엄격 모드 오류 없이 두 시작점의 A/A가 모두 비트 단위 동일한 경로 중 라운드 업데이트 시간(두 A/A 실행 평균)이 짧은 쪽. 둘 다 통과하지 못하면 S9를 멈추고 연구자에게 넘긴다.
  ManiSkill GPU 시뮬레이션은 torch 결정적 모드에서 인덱스 대입이 실패하므로(S6 스모크에서 확인), 결정적 플래그는 환경 호출(생성·리셋·스텝) 동안만 끄고 정책·학습기 경로에는 켠다 (`g2_gpu.sim_nondeterministic_ok`).
- A3⁰: 통제 PPO (C7·C9·C10), terminal 보상, γ 0.99, λ 0.95, clip 0.2, 1 에폭, 미니배치 8 × 누적 20, LoRA lr 1e-4, value head lr 3e-3, 기울기 클리핑 10 (LoRA·value head 함께), 미니배치 순서 시드 = 1000 + r.
- 체크포인트: A3⁰·A2⁺ 라운드 10·50 (학습 가능한 파라미터 + optimizer 상태). S7의 두 번째 측정은 A3⁰ 라운드 10 체크포인트에서 새로 수집한 배치로 한다.
- 비용 외삽: 390라운드 1회 GPU 시간 = 측정 라운드 평균 시간 × 390 (A3⁰·A2⁺ 각각). A2⁺의 라운드 시간은 성공 수에 따라 달라지므로 측정 구간 평균을 쓰고, 이 한계를 함께 적는다.
