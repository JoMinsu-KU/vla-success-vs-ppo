- 직전 외부 검토: 4차(v0.7 대상, 2026-10-15). v0.8~v0.11의 변경은 외부 검토를 받지 않았다. v0.8은 4차 검토 반영, v0.9는 내부 상세 검토 반영이다. **이번 요청의 중심은 v0.10·v0.11, 즉 4090 파일럿 결과로 바꾼 설계다.**

## 1. 지금 상태 한 문단

공개 RL4VLA 코드·체크포인트로 Windows RTX 4090에서 파일럿 P1~P6을 마쳤고, G1(구현 검증 게이트)을 **통과(조건부)**로 확정했다 (`pilot/G1_report.md`, 이탈 기록 D-006). 다음은 G2(H200 실측)와 G-PRE(본실험 사전 고정)다. 연구 질문·갈래(A1·A2⁺·A2±·A3⁰·A3ˢ)·E1~E4 구조·주지표(실행 축 Δ_rep 비열등성)·시드 배정은 4차 검토 이후 바뀌지 않았다.

## 2. 검토해 주셨으면 하는 변경 (우선순위 순)

### 2.1 새 통제 항목 C10 — 생성 경로 대 teacher forcing 경로의 log-prob 차이 (3.2절)

- **발견:** 같은 행동 토큰의 joint log-prob가 생성(`generate`, prefill + KV 캐시 증분)과 학습(`evaluate_action`, 한 번의 teacher forcing forward)에서 다르다. LoRA가 붙은 학습 경로에서 평균 0.20, 95% 0.50, 최대 0.95 nats, **θ_old에서 이미 전이의 42%가 ratio 클리핑 범위(±0.2) 밖**이다. 재토큰화(0/12)·softmax 정밀도는 원인이 아니고, 같은 위치 로짓이 bf16 몇 ulp씩 다른 것이 32개 층을 거치며 쌓인 결과다. 근거: `pilot/P4_results.md`, `pilot/P4_results_ppo_e2.md`, `pilot/p4/diag_roundtrip.py`.
- **결정 (v0.11):** 통제 연구의 모든 PPO 학습(A3⁰·A3ˢ·E2 네 칸·A3⁰₊)에서 라운드 업데이트 전에 θ_old의 teacher forcing 경로로 old log-prob와 old value를 다시 계산한다. 업데이트와 같은 미니배치 묶음으로 계산하면 첫 ratio가 비트 단위로 1이다 (4090 확인).
- **질문:**
  1. 이 처리로 "θ_old에서 ratio = 1"은 맞췄지만, 행동은 여전히 생성 경로 분포 q에서 뽑히고 학습은 teacher forcing 분포 π로 한다. q ≠ π에 대한 중요도 보정 없이 두는 것이 통제 연구로서 충분한가? 대안(예: 생성 경로 로짓을 학습에도 쓰는 방식, q/π 보정)을 검토해야 하는가?
  2. old value도 다시 계산하고(GAE·value 클리핑에 사용) 생성 때 value는 버린다. 타당한가?
  3. v0.10은 A3ˢ(원 보상 PPO)를 원 레시피에 가깝게 두려고 C10에서 뺐는데, v0.11은 A3⁰ 대 A3ˢ가 보상만 달라야 한다는 이유로 A3ˢ에도 적용했다. 그러면 A3ˢ를 "실용 기준선(원 PPO)"이라고 부르기 어려워진다. 이 선택과 이름이 적절한가?

### 2.2 새 통제 항목 C11 — 결정적 GPU 실행 (3.2절)

- **발견:** 기본 GPU 설정에서 같은 체크포인트·배치·미니배치 순서·optimizer 상태로 한 업데이트가 실행마다 다르다. E2의 C± 분기와 계보의 실제 다음 상태가 LoRA 업데이트 노름의 39%만큼 달랐다 (Adam이 기울기 0 근처의 작은 차이를 부호 차이로 키움). 결정적 설정(math SDPA, `use_deterministic_algorithms`, `CUBLAS_WORKSPACE_CONFIG`)에서는 비트 단위로 같았고 시간은 +30~45%. 근거: `pilot/P4_results_ppo_e2.md`, `pilot/p4/test_branch_determinism.json`.
- **결정:** E2 계보와 모든 분기는 필수. 기본안은 모든 학습·평가에 적용, H200 비용을 G2에서 재고 G-PRE에서 범위 확정. 갈래마다 다르게 적용하지 않는다.
- **질문:**
  4. 결정적 설정은 attention 커널(수치)도 바꾼다. E1 전체에 적용하지 않고 E2 계보(A3⁰)에만 적용하면 E1의 A3⁰과 A2⁺가 다른 커널로 학습된다. "모든 학습에 적용"이 기본안인 것이 맞는가, 아니면 E1은 기본 설정으로 두고 비결정성을 시드 분산의 일부로 보는 것이 나은가?
  5. E2 네 칸 차이에 들어가는 비결정성 잡음을 없애는 것이 목적이다. 결정적 설정 말고 "같은 분기를 여러 번 반복해 평균" 같은 대안이 더 나은 경우가 있는가?

### 2.3 E4-b 공통 상태 복원 절차와 평가 재현성 (3.8절)

- **발견:** 집기 접촉 중인 상태는 상태 벡터(물리·제어기·과제)를 복원해도 같은 행동을 재생한 결과가 복원할 때마다 다르다 (7/7). 같은 프로세스의 이전 에피소드 이력이 리셋 뒤에도 물리 엔진 내부(접촉 캐시 등)에 남기 때문이다. 장면을 재구성(`reconfigure=True`)한 뒤 전체 상태를 복원하면 7/7 비트 단위로 반복 재현된다 (0.28초). 리셋 뒤 행동열 재생은 반복 재현되지 않았다. 근거: `pilot/P4_results_storage_restore.md`.
- **결정:** S_rec = (episode_id, 전체 상태 벡터), 평가 때마다 장면 재구성 + 전체 상태 복원. 판정 기준은 원 궤적과의 일치가 아니라 반복 재현성. 평가 에피소드도 매번 장면 재구성.
- **질문:**
  6. S_rec를 "이 절차로 복원한 상태"로 정의하면 기준 정책(W1)이 실제로 지나간 상태와 정확히 같지 않다 (원 궤적과는 접촉 중 다르게 진행). E4-b의 해석("같은 교란 상태에서의 회복 능력")에 문제가 되는가?
  7. 본실험(Linux GPU 시뮬레이션, 환경 64개)에서는 E4-b를 CPU 시뮬레이션·환경 1개로 따로 해도 되는가? (평가 축 간 시뮬레이션 백엔드가 달라짐)

### 2.4 평가 방식 (3.8·4.1절)

- **발견:** P2에서 시드(64개 묶음) 간 성공률 SD가 새 물체 과제에서 이항 잡음의 약 2배였고, 원인은 묶음마다 다른 물체 구성이었다. 근거: `pilot/P2_results.md`.
- **결정:** 모든 갈래·시드·체크포인트를 같은 고정 `episode_id` 집합(조건당 192개)으로 평가하고, 에피소드 수준 짝지은 비교를 기술 보고로 함께 낸다. 주 분석은 여전히 시드 단위 Welch.
- **질문:**
  8. 고정 집합을 쓰면 갈래 간 비교가 초기 상태에 대해 짝지어진다. 주 분석(시드 단위 Welch)을 바꿀 필요가 있는가, 아니면 짝지음은 분산을 줄이는 쪽으로만 작용하므로 그대로 두는 것이 보수적이고 맞는가?
  9. 고정 집합 하나에 대한 성공률은 모집단 평균과 구성 몫만큼 다를 수 있다 (절대 성공률 보고에 영향). 보고 방식이 적절한가 (4.1절)?

### 2.5 우도 갈래 안정화 장치의 KL 정의 (3.3절)

- **발견:** P5(A2⁺ 2시드 × 10라운드)에서 성공 전이만으로 계산한 k3 KL이 13~1,456으로, 선택 편향 때문에 해석할 수 없었다. AdamW 첫 스텝만으로도 학습 데이터의 토큰 NLL이 크게 줄었다. 근거: `pilot/P5_results.md`.
- **결정:** 고정 탐침 상태(성공·실패를 가리지 않고 고른 64개)에서 위치별 256 bin 분포의 정확한 KL. KL_max는 G2의 원 PPO 같은 측정값 분포로.
- **질문:**
  10. PPO의 라운드당 KL 분포로 우도 갈래(A2⁺·A2±)의 상한을 정하면 갈래 사이 공정성에 문제가 없는가? 우도 갈래 학습률(1e-4·3e-4)을 낮추는 쪽이 더 나은가?

### 2.6 통계 (4.5절)

- 절차 전체 시뮬레이션(2만 회): 맹검 재추정 절차의 경계 1종 오류 0.047~0.055 (명목 0.05, 최대 +0.005), 분석 함수 세 개는 명목과 일치, 비열등성 순열 검정(δ 이동·studentized)은 이분산에서도 0.050. 근거: `pilot/stats/GPRE_simulation.md`.
- **질문:**
  11. +0.5%p 이내의 팽창을 받아들이고 기록할지, 최종 α를 낮출지 (G-PRE 결정 항목). 권고가 있는가?

### 2.7 신규성 (2.1·2.3절, G0)

- 2026-10-19 확인: 같은 RL4VLA 설정에서 PPO를 동일 예산으로 오프라인 시연 정규화와 비교한 연구(2607.19399), 동일 예산에서 filtered SFT와 Q 기반 방법을 비교한 연구(2608.21204), LLM 추론 RL의 음의 표본 연구(2505.18830 등)가 있다. 자기 성공 롤아웃 갈래 대 VLA PPO의 동일 예산 비교와, VLA에서 추정기를 고정한 음의 항 제거 실험은 찾지 못했다. 근거: `pilot/G0_check_2026-10-19.md`.
- **질문:**
  12. 2.3절 문단(기여 = 동일 예산 대체 가능성 평가 + 추정기를 고정한 동일 배치 음의 항 제거 + 공통 상태 회복 평가의 조합)이 여전히 유지되는가? 2607.19399와의 차별화를 어떻게 쓰는 것이 좋은가?

### 2.8 파일럿 판정 (6.5절, 이탈 기록)

- G1을 "통과(조건부)"로 확정했다 (D-006). 판정표에 없는 범주이고 결과를 본 뒤의 판정이다. 조건: 위 통제 방법의 명세 반영(완료), 64 환경 전체 규모 손실·기울기 확인은 G2에서.
- P2 재현에서 SFT 새 물체가 허용 범위 상한을 0.4%p 넘은 것을 조건부 통과로 재판정했다 (D-002).
- 파일럿 환경에서 학습 조건의 RL − SFT 격차가 +1.6%p로 원 논문(+15.7)과 크게 달랐고, 실행 축 격차는 같았다 (1.2절 상자).
- **질문:**

## 3. 다시 논의하지 않아도 되는 것

4차 검토까지 확정된 것: 연구 질문과 갈래 구성, terminal 보상(A3⁰), E2 2×2와 D_C·I 분리, E4-a/E4-b 구분, 결과 방향과 무관한 외부 검증, 보조 확증 세 묶음과 묶음별 오류 통제, MDE 정의. v0.9의 내부 검토 반영(δ의 G2 오염 차단, A2⁺ 업데이트 방식 튜닝 축, K0/K50 규칙, critic 시간 관측 대안 등)은 검토해 주시면 좋지만 우선순위는 낮다.

## 4. 회신 형식 (제안)
