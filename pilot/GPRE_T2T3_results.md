- 기준 상태는 "집기가 2스텝 이어진 직후"라 물체가 대부분 거의 들리지 않았다. 기록된 W1 행동은 그리퍼를 닫는 행동이어서, 물체가 거의 제자리에 있으면 다음 스텝에 바로 다시 집힌다. 다시 집히지 않은 10개는 대부분 8~17 mm 들려 있다가 떨어진 원소다 (1, 9, 11, 13, 18, 22, 23. 나머지 6·12·14는 들리지 않았는데도 다시 집히지 않음).
- 따라서 R-a′는 원소의 절반 정도에서 "한 번 열었다가 닫으면 회복되는" 약한 교란이다. 정책이 계속 닫기 행동을 내면 바로 회복하므로, E4-b의 R-a′ 차이는 주로 들려 있던 원소에서 생길 것이다. 이것은 관측이고 규칙 위반은 아니다. 교란을 더 강하게 바꿀지(예: 열린 상태를 몇 스텝 유지)는 재정의에 해당하므로 G-PRE에서 연구자가 정한다.
- 집기 래치는 복원값(켜짐)을 유지한다 (R-a와 같음). 그래서 성공 Y는 다시 집지 않고 물체를 접시로 밀어 넣어도 인정된다. 이 점도 R-a에서와 같다.

## 2. T3. 평가 잡음 (GPU, 공개 RL 체크포인트, 실행 3조건 × 192)

평가 1 = S4 결과, 평가 2 = 칸 배정만 바꾼 재평가 (고정 순열, 에피소드마다 배치·칸·이웃·샘플링 난수가 바뀜. 같은 배치·같은 칸에 놓인 에피소드는 조건마다 0~1개).

| 조건 | 평가 1 Y | 평가 2 Y | 차이 | 불일치 (1만 성공 / 2만 성공) | McNemar p | 평가 잡음 SD | 이항 SD |
|---|---|---|---|---|---|---|---|
| Position | 78.6 | 75.0 | −3.6 | 49 (28 / 21) | 0.39 | 2.58 | 3.05 |
| EEPose | 76.6 | 80.2 | +3.6 | 41 (17 / 24) | 0.35 | 2.36 | 2.97 |
| PositionChangeTo | 79.2 | 82.8 | +3.6 | 35 (14 / 21) | 0.31 | 2.18 | 2.83 |
| **실행 축 평균** | 78.1 | 79.3 | +1.2 | | | **1.37 (1.26~1.47)** | 1.70 |

(단위 %p. 평가 잡음 SD = √(D / 2N²), 실행 축 = √(ΣV̂) / 3. 괄호는 에피소드 붓스트랩 95% 구간.)

- **분산 비 r = 0.65 (0.56~0.75).** 고정 집합에서는 에피소드마다 성공 확률이 다르고(쉬운 초기 상태는 거의 항상 성공), 평가 잡음은 Σp_e(1−p_e)만 남는다. 그래서 이항 가정보다 작다. 사전 고정에서 예상한 방향(r ≤ 1)이다.
- **배치 안 상관 점검 (참고, 자유도 3):** 조건별 평균 차이로 잰 분산 Σ(Ȳ₁ − Ȳ₂)²/2 = 0.00199, 에피소드 불일치로 잰 ΣV̂ = 0.00170. 비는 1.18로 자유도 3에서 1과 구별되지 않는다. 같은 배치 안 결합(F3)이 성공률 분산을 크게 키운다는 증거는 없다. 다만 붓스트랩 구간은 에피소드 독립을 가정하므로, 배치 안 상관이 조금 있다면 구간이 좁게 나온 것이다.
- 세 조건 모두 평가 간 차이가 3.6%p(7/192)이고 McNemar p 0.31~0.39다. 한 조건 평가 차이의 기대 SD(√2 × 2.2~2.6 ≈ 3.1~3.6%p)와 맞는다.
- **재현 점검:** EEPose 배치 0을 S4와 같은 칸 배정·시드(1000)로 다시 돌린 결과는 64개 모두 Y와 기록된 모든 필드가 S4와 같다 (51 / 64). 평가 경로는 프로세스·날짜와 무관하게 칸 배정과 샘플링 시드로 결정된다. 따라서 평가 잡음은 전부 "어느 칸에 어떤 이웃과 놓이는가 + 샘플링 난수"에서 온다.

**T1에 넣는 값 (사전 고정 규칙):** 주 가정 **1.4%p** (1.373을 0.1 단위로 올림), 민감도 **1.47%p** (95% 상한). 성공률 약 78% 체크포인트 하나에서 잰 값이므로, 다른 성공률 p에서는 √(0.65 · p(1−p) / 576)로 환산한다 (예: p = 50%에서 1.68%p, 명세 표기 2.1%p 대비).

- **한계:** 체크포인트 하나(공개 RL)에서 쟀다. 본실험 체크포인트는 LoRA 자체 학습분이고 성공률 분포가 다를 수 있다. r은 "초기 상태별 성공 확률이 얼마나 갈리는가"에 달려 있어 정책마다 다를 수 있다.

## 3. G-PRE 초안에 반영할 곳 (제안)

- 5절 E4-b: R-a′ 제외 0 / 21, R-c 제외 2 / 21 → 교란 4종 유지. R-a′가 원소 절반에서 1스텝 안에 회복되는 약한 교란이라는 관측을 해석 범위에 덧붙일지 결정.
- 1절·T1: 평가 잡음 항 1.8 → 1.4%p (민감도 1.47). 시드 단위 SD = √(σ² + 1.4²).
- 1절 추정 대상 문구: "물리 경로는 고정되지 않음"에 더해, 같은 칸 배정에서는 평가가 비트 단위로 재현되고 평가 잡음은 실행 축 평균에서 약 1.4%p라는 측정값을 인용할 수 있다.
