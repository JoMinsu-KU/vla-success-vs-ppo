- 1차와 다른 점: (a) 필요 n을 **사전 고정 표**(맹검 SD를 0.1 단위로 반올림 → n, 8~12)로 결정 (1차는 캐시 키만 반올림하고 계산은 최초 입력 SD로 해서 실행 순서 의존), (b) 순열 검정은 12,870개 분할 **전체 열거** (1차의 `SPLITS[::10]`은 균일 표집이 아님), (c) 최종 α 0.05·0.045·0.04, (d) 학습 초기화 시드 블록 안의 상관 ρ(C2)에서 Welch 대 블록 짝지은 t, (e) 1차와 다른 난수 시드(20261020).
- 가정: δ = 5%p, Δ_plan = 0, SD = √(σ² + 1.8²). 반복: ρ = 0은 40,000회(1종 오류 MC SE 약 0.0011), ρ ≠ 0은 10,000회(약 0.0022). 1차 결과(gpre_sim.py)는 결함을 주석으로 표시하고 그대로 둔다.

**해석:**
1. 1차의 n 표 결함을 고쳐도 적응형 절차의 팽창은 남는다: ρ = 0, α 0.05에서 Welch 0.050~0.053, 짝지은 t 0.051~0.054 (고정 n은 명목). 최종 α 0.045에서 둘 다 0.045~0.049로 명목 이하.
2. **블록 상관이 음수이면 Welch의 1종 오류가 0.074~0.078로 크게 팽창한다.** "짝짓지 않는 쪽이 보수적"(v0.11 C2)은 틀렸다. 양수면 Welch가 지나치게 보수적이고 검정력을 잃는다.
3. 블록 짝지은 t는 ρ와 무관하게 명목 근처(α 0.05에서 0.049~0.057)이고, α 0.045에서 0.044~0.051.
4. 블록 상관 ρ는 아직 모른다. ρ의 부호에 따라 Welch가 크게 틀어지는 반면 짝지음은 안정적이므로, **G-PRE 후보: 주 분석 = 시드 블록 짝지은 t, 최종 단측 α = 0.045 (대칭 구간 91%), Welch는 민감도.** 짝지음에서 맹검 재추정에 쓰는 분산(현재: 합동 분산)과 n 표를 차이의 분산 기준으로 바꿀지, 그 경우의 재보정은 최종 채택 구조로 G-PRE에서 다시 시뮬레이션한다. ρ < 0에서 짝지음의 검정력이 낮아지는 점(σ 4에서 0.68)도 함께 고려한다.
