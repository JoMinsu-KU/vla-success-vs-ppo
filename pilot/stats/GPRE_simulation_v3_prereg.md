## 1. 최종 구조 (시뮬레이션 대상)

- 블록 = 학습 시드 s. 블록 차이 d_s = Ȳ(A2⁺, s) − Ȳ(A3⁰, s) (실행 축 평균, %p). H₀: E[d] ≤ −δ, δ = 5.
- 판정: 짝지은 t의 단측 하한 d̄ − t_{1−α, n−1} · s_d / √n > −δ. **최종 α = 0.045** (91% 양측 구간).
- 적응형 n: 블록 4개가 끝나면 맹검 SD_d를 계산해 0.1 단위로 반올림하고, 아래 n 표에서 n(8~12)을 정한다. 앞 4블록은 최종 분석에 그대로 들어간다.
- **n 표:** 짝지은 t(자유도 n−1), α 0.045, Δ = 0에서 검정력 0.8을 주는 최소 n을 8~12로 자른다. 계산 결과 SD_d < 5.0 → 8, 5.0~5.3 → 9, 5.4~5.7 → 10, 5.8~6.0 → 11, ≥ 6.1 → 12.

**맹검 SD_d 후보:**
- **P (주 후보):** s_d = √(Σ_{s=1..4} d_s² / 4). 블록 안 두 값의 갈래 이름을 바꿔도 d²는 같으므로, 스크립트는 갈래를 몰라도 계산할 수 있다 (블록 = 학습 시드는 맹검 대상이 아님). Δ_plan = 0 가정이라 평균을 빼지 않는다. 운영상 노출되는 것은 |d_s|의 제곱 평균 하나이고 부호는 나오지 않는다.
- **W (대조, 2차 방식):** 8개 값의 합친 표본분산 s²에서 s_d = √2 · s (ρ = 0 가정).

## 2. 자료 모형

a_s = Δ + σ z₁ + e₁, b_s = σ z₂ + e₂. corr(z₁, z₂) = ρ (학습 초기화 공유에 의한 블록 상관, 학습 몫에만), e ~ N(0, 평가 잡음²) 독립.

| 축 | 값 |
|---|---|
| σ (학습 시드 SD, 갈래당) | 3, 4, 5, 6 |
| ρ | −0.3, 0, +0.3, +0.6 |
| 평가 잡음 | **1.4 (주, T3)**, 1.47 (T3 95% 상한), 1.68 (성공률 50% 환산) |
| 반복 | 칸마다 경계(Δ = −δ) 40,000회, 검정력(Δ = 0) 40,000회 (MC SE 약 0.0011) |

W는 평가 잡음 1.4에서만. 대조로 고정 n = 8·12 (ρ 0·−0.3, 평가 잡음 1.4). 민감도로 Welch(같은 자료), 블록 안 부호 뒤집기 순열 검정(δ 이동 뒤 studentized, 2ⁿ 전체 열거, 적응형 P, σ 3·6 × ρ 0·−0.3, 10,000회).

## 3. 판정 규칙 (실행 전에 고정)

1. **맹검 추정량 선택:** 평가 잡음 1.4의 16칸(σ × ρ)에서 α 0.045 경계 1종 오류 점추정의 최대값이 **0.050 이하**인 후보를 쓴다. 둘 다 만족하면 **P**를 쓴다 (ρ를 반영하는 추정량이고, 짝지은 분석과 구조가 같다). 둘 다 넘으면 아래 3번으로 간다.
2. **α 0.045 유지:** 고른 추정량에서 위 조건을 만족하면 최종 α 0.045를 유지한다. 평가 잡음 1.47·1.68 칸에서 0.050을 넘는 칸이 있으면 그 사실을 보고하되 α는 바꾸지 않는다 (주 가정은 1.4).
3. **α 낮춤 (위가 실패할 때만):** α 0.04에서 1번 조건(최대 ≤ 0.050)을 만족하면 최종 α 0.04 (구간 92%)로 하고 n 표를 α 0.04로 다시 계산해 한 번 더 시뮬레이션한다. 0.04도 실패하면 G-PRE 초안에 실패로 기록하고 연구자가 정한다.
4. 검정력, 평균 n, Welch, 순열 결과는 판정에 쓰지 않는 보고 항목이다. 검정력이 낮은 칸(σ ≥ 5에서 n = 12 상한)은 명세 R8의 정밀도 한계로 보고한다.
5. 결과를 본 뒤 격자·규칙·추정량 후보를 바꾸지 않는다. 바꿔야 하면 이탈로 기록한다.
