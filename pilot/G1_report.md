# 파일럿 종합 보고와 G1 판정 (RTX 4090 워크스테이션)

- 작성: 2026-10-17 · 갱신: 2026-10-19 (P4 2·3차 반영)
- 범위: 연구 명세 v0.9의 파일럿 P1~P6 중 이 워크스테이션(Windows 11 + RTX 4090 24 GB + WSL2)에서 할 수 있는 것 전부.
- 원칙: 파일럿은 구현 정상 동작 확인과 본실험 설계용 측정이다. **여기의 수치는 논문 근거로 쓰지 않는다** (6.1절).
- **승인 범위 (2026-10-19, 6차 외부 검토 반영, 명세 v0.12 6.5절):** G1 통과(조건부)는 **G2 진입 승인**이다. 본실험 착수 승인은 G-PRE에서 한다. 아래의 "C10 반영 왕복 시험 통과"는 trainer 기준 ratio 정렬(첫 ratio = 1)의 통과이며, 생성 경로와 teacher forcing 경로의 분포가 같다는 뜻이 아니다. 잔여 불일치는 G2에서 잰다. "실행 축 격차 재현"은 P2에서 평가한 실행 두 조건(EEPose, PositionChangeTo)에 대한 것이고, Position 조건을 포함한 실행 축 전체는 G2의 Linux 경로 재평가에서 확인한다.

## 3. 파일럿에서 새로 알게 된 것 (설계에 영향)

1. **생성 경로와 teacher forcing 경로의 log-prob 차이 (C10 후보).** 같은 행동 토큰의 log-prob가 KV 캐시 증분 디코딩과 한 번의 forward에서 최대 0.29 nats 다르다 (bf16 로짓 몇 ulp 차이의 누적). 원 PPO는 θ_old에서도 ratio가 약 0.75~1.33이다. → 업데이트 전 teacher forcing으로 old log-prob를 다시 계산하는 통제 제안.
2. **KL 안정화 장치의 측정 방식.** 성공 행동만으로 k3 KL을 추정하면 선택 편향으로 쓸 수 없는 값이 나온다 (13~1,456). → 고정 탐침 상태에서 256 bin 정확한 KL로 바꾸는 제안. 첫 AdamW 스텝 하나로도 정책이 크게 움직인다.
3. **평가 초기 상태의 구성이 큰 잡음원.** 새 물체 과제에서 시드 간 SD가 이항 잡음의 약 2배이고, 물체별 성공률이 3배 차이 난다. → 모든 체크포인트를 같은 고정 초기 상태 집합으로 짝지어 평가 (4.1·3.8절 반영 제안).
4. **W1의 성공률은 온도(0.6~1.0)와 top-k(0/50)에 거의 둔감하다** (44% 안팎). K0을 쓰는 비용이 없다.
5. **A2⁺의 성공 데이터 공급은 충분하다** (라운드당 약 28~30개, 0-성공 라운드 0). U-prop의 스텝 수는 PPO의 약 44%. 성공의 약 20%에 놓쳤다 다시 집는 회복 행동이 들어 있다.
6. **성공 필터의 물체 편향:** 물체별 수집 성공률 23~66%. A2⁺ 데이터가 쉬운 물체로 2~3배 치우친다.
7. **원 논문과 학습 조건 격차가 다르다:** 이 환경에서 RL − SFT 학습 조건 격차가 +1.6%p(원 논문 +15.7%p). 실행 축 격차는 같다. ID 대비 하락 해석에 영향.
8. **맹검 재추정 절차의 1종 오류 팽창은 작다** (경계에서 0.047~0.055). δ < 5%p에서는 검정력이 크게 떨어진다.
9. **평가 비용이 크다.** 4090에서 체크포인트당 7.8시간. 본실험 예산의 평가 몫을 G2에서 실측해야 한다.
