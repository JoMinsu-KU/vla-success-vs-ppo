## F3. GPU 64개 배치 복원 재현성

GPU 시뮬레이션은 64개 환경이 한 PhysX 장면을 공유한다. 같은 S_rec 원소가 **배치 안 위치**나 **옆 환경 구성**에 따라 다르게 굴러가면 E4-b를 GPU에서 할 수 없다.

**재생 시험 (판정):** S_rec 원소마다 기록된 W1 행동 25스텝(S8 A부와 같은 구간)을 재생하고, 매 스텝 그 환경의 전체 시뮬레이터 상태(`get_state()[i]`)와 RGB 픽셀(SHA-256)을 저장한다. 교란 4종(대조·R-a·R-b·R-c) 각각에서 아래 배치 구성으로 돌린다.

| 구성 | 64칸 배치 | 무엇을 바꾸나 |
|---|---|---|
| L0 | 칸 i ← 원소 i mod 24 (원소마다 2~3칸) | 기준. 같은 배치 안의 중복 칸끼리도 비교 |
| L0r | L0를 다시 실행 | 같은 배치 반복 |
| L1 | 칸 i ← 원소 (5i + 3) mod 24 | 위치와 이웃 원소가 모두 바뀜 |
| L2 | 짝수 칸 i ← 원소 (i/2) mod 24, 홀수 칸 = S_rec이 아닌 다른 장면(새로 초기화, 복원 없음) | 이웃이 전혀 다른 장면 |
| L0s | L0와 같되 reset 시드를 칸 번호로 (S8 GPU 작업자 방식) | reset 시드가 복원 뒤 결과에 남는지 |

- reset 시드는 L0s를 빼고 모든 칸 0 (S8 CPU와 같음).
- **판정:** 타당 원소 21개 × 교란 4종에서, 같은 (원소, 교란)의 모든 칸(배치 안 중복, L0·L0r·L1·L2·L0s)이 25스텝 내내 상태와 픽셀 모두 **비트 단위로 같으면 통과**. 하나라도 다르면 "현 절차로는 GPU E4-b 불가"로 보고하고, 어긋난 비율, 처음 어긋난 스텝, 핵심 상태(물체·접시 위치, 관절) 최대 차이를 함께 낸다.

**닫힌 고리 진단 (기술 보고, 판정 아님):** S8에서 RL의 대조 성공률이 CPU 95.2, GPU 71.4로 갈린 원인을 가르기 위한 것이다.
- GPU: RL 정책(S8과 같은 설정, 온도 0.6), 대조, H = 40. 구성 L0(시드 a)·L0 반복(시드 a)·L1(시드 a)·L0(시드 b). 원소별 성공 수와 구성 간 성공률 차이를 낸다.
- CPU: RL, 대조, 타당 원소 21개를 S8과 다른 샘플링 시드 2개로 더 돌려(S8의 900+j에 더해 2900+j, 4900+j) CPU 안의 샘플링 변동을 잰다.
- 해석 규칙: CPU 반복 간·GPU 구성 간 성공률 변동이 S8의 CPU–GPU 차이(23.8%p)와 비슷하면 그 차이는 샘플링 잡음으로 설명된다고 쓰고, 훨씬 작으면 백엔드 차이로 쓴다. 원소 21개라 이항 SE가 약 10%p임을 함께 적는다.

## F4. R-a 관통 검사 규칙

**제외 규칙 (정책 평가와 무관, CPU에서 판정):** 타당 원소 21개 각각에 대해 복원 → R-a 적용 뒤,
1. **교란 직후 관통:** PhysX 서브스텝 1회(2 ms, 제어 입력 없음) 뒤 접촉점에서, 집을 물체와 다른 모든 물체(테이블, 접시, 로봇 링크, 그 밖의 물체) 사이 관통 깊이(접촉 separation의 음수) 최대값 > 5 mm이면 제외.
2. **1스텝 뒤 (S_rec 타당성 기준 그대로):** 다시 복원 → R-a → 기록된 W1 행동 1스텝(0.2 s, S8 B부와 같은 행동) 뒤, 관통 > 5 mm 또는 집을 물체·접시 선속도 > 0.5 m/s이면 제외.
3. 둘 중 하나라도 걸리면 제외한다. **다른 자리로 옮기지 않는다** (옮기면 원소마다 교란의 정의가 달라진다).

- 1번을 더한 이유: 0.2 s 한 스텝(서브스텝 100회) 동안 PhysX가 겹침을 밀어내 풀어 버리므로, 스텝 뒤 관통만 보면 교란이 만든 겹침을 놓칠 수 있다. 속도 기준이 이를 일부 잡지만 직접 측정을 함께 둔다.
- **제외 수를 보고한다. 21개 중 1/4을 넘으면(6개 이상) R-a 정의 자체를 G-PRE에서 다시 본다** (이 시험에서 정의를 바꾸지 않는다).
- GPU 쪽은 접촉 질의 방식이 달라 판정에 쓰지 않는다. GPU의 1스텝 뒤 속도는 기술 보고한다.

**재실행 (제외 뒤 남은 원소):**
- 초기 전이: 같은 기준 상태 + R-a + 같은 행동 1스텝 뒤 CPU 대 GPU의 핵심 상태 차이(물체·접시 위치 m, 관절 rad). 행동은 S8에서 W1·SFT·RL 각 정책이 CPU에서 낸 첫 행동(`C_cpu_*.pkl`)과 기록된 W1 행동. 중앙값·최대값과 1 cm 넘는 원소 수를 낸다. 대조·R-b·R-c도 같은 방식으로 다시 재서 비교 기준으로 둔다.
- 성공률: 정책 롤아웃은 새로 하지 않는다. S8 C부의 원소별 결과에서 남은 원소만 골라 R-a 성공률을 다시 계산한다 (기술 보고).

**B부 관통 측정 점검 (기술 보고):** S8 B부는 관통을 복원 직후 물리 스텝 없이 읽었다. 이때 접촉 목록은 직전 시뮬레이션 스텝의 것이어서 복원 상태를 반영하지 않았을 수 있다. 그래서 대조(교란 없음) 상태에도 위 1·2번 측정을 똑같이 해서 S_rec 24개의 관통을 다시 보고한다. 5 mm를 넘는 원소가 나오면 S_rec 제외 여부는 G-PRE에서 정한다 (이 시험에서 S_rec을 바꾸지 않는다).
